# Reviews

- `AR-XXXX-slug.md` — architecture reviews (`templates/architecture-review.md`)
- `CR-XXXX-slug.md` — code reviews of a pull request, diff or module (`templates/code-review.md`)

Reviews cite the files and commits read. Findings that are not fixed right away go to
`tech-debt.md`. Never delete a review; mark it `status: superseded` and link the newer one.
Reviews never contain copies of large code blocks or any secret values.
